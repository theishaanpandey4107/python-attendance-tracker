# python-attendance-tracker
A beginner Python project to manage student attendance.
## Features
- Add student names and roll numbers
- Mark students as present or absent
- Store attendance records in a Python dictionary

## Concepts Used
- Python functions
- Dictionaries
- Conditional statements
- Function parameters

## How to Run

1. Install Python 3.
2. Download or clone this repository.
3. Open the project folder in your terminal.
4. Run:

   `python3 attendance_tracker.py`

## Future Improvements
- Record attendance across multiple days
- Calculate attendance percentages
- Save records to a file
