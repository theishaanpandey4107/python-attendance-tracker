# 🐍 Python Attendance Tracker

A beginner-friendly, menu-driven attendance management system built using Python. This project helps manage student records and mark students as present or absent.

## 🚀 Features

- **Add Student:** Enter a student's name and roll number.
- **Mark Attendance:** Set a student's status as Present or Absent.
- **View Attendance:** Display the saved student records.
- **Menu-Driven Interface:** Choose actions through a simple terminal menu.
- **Multiple Student Records:** Store records using Python dictionaries.

## 🛠️ Technologies Used

- Python 3
- Dictionaries
- Functions
- Conditional Statements (`if-elif-else`)
- Loops (`while`, `for`)
- User Input and Output

## 💻 How to Run

### 1. Install Python

Install Python 3 if it is not already installed.

### 2. Clone This Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

Replace `YOUR_GITHUB_REPOSITORY_URL` with this repository's actual URL.

### 3. Open the Project Folder

```bash
cd python-attendance-tracker
```

### 4. Run the Program

```bash
python3 attendance_tracker.py
```

## 📋 How to Use

When the program starts, the following menu appears:

```text
1 - Add student
2 - View attendance
3 - Exit
```

- Enter `1` to add a student and select their attendance status.
- Enter `2` to display student attendance records.
- Enter `3` to exit the program.

## ⚠️ Current Limitations

- Attendance records are stored in memory and are lost when the program exits.
- Each student is currently identified by their name.
- The program runs in the terminal and does not have a graphical interface.
